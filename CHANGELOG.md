# Changelog

## 0.0.1

Initial Marketplace release.

- Signature scanning: function selectors, event topics, and error selectors for every contract in the workspace
- Real-time gas estimation with inline decorations (runner, forge, or solc backend)
- Security analysis: reentrancy, unchecked calls, access control, missing events, dangerous patterns, DeFi risks, MEV
- Deploy & Run panel: compile, deploy, call functions, and verify without leaving the editor
- EVM toolbox: calldata encode/decode, ABI encode/decode, unit conversion, keccak hashing, address computation
- On-chain inspection: transactions, addresses, events, and contract state across 8 chains
- Copilot agent-mode language-model tools (selectors, audits, calldata, hashing)
